What was actually sent

Password exposure check (k-anonymity)

The password is hashed in your browser with SHA-1. Only the first five characters of that hash are sent - to this server, and then to api.pwnedpasswords.com. The remaining 35 characters, the full hash and the password itself are never transmitted to this server, never stored and never logged. This app has no endpoint that accepts a password. This check is free and needs no API key. The request asks HIBP to pad its answer, so the size of the response does not reveal how common your prefix is; the padding entries (always a count of 0) are discarded before your browser compares the remaining 35 characters locally.

Not stored anywhere. Password checks are never added to scan history and are never written to this server's disk or logs. Clearing the field or reloading the page discards everything.
Browser-side hashing unavailable. This page is not running in a secure context (HTTPS or localhost), so crypto.subtle is disabled by your browser. Rather than sending your password to the server, the check is turned off. Open the hosted HTTPS URL to use it.

Scan history (this device only)

History is stored in your browser's localStorage - not on the server. Deleting it here removes it from this device permanently. Shared or public computers: delete your scans when you finish.

Optional API keys

Everything works without keys. Keys are stored only in this browser, are sent to this server once per request (over the same HTTPS origin), and are never logged, cached or written to disk. Sources that need a key you did not supply are reported as Not checked, never as “no matches”.

What Verdigris is

Verdigris is a free, open, evidence-first public-source intelligence (OSINT) and privacy checker. It queries public, mostly keyless APIs and shows you what each source actually returned, with the timestamp, the supporting evidence and a direct link, so you can verify every claim yourself.

Independent project. Verdigris is not affiliated with, endorsed by, or connected to Serus (serus.ai) or its operators. It is a functional alternative built from public sources only, and the name refers to the teal-green patina that forms on copper.
